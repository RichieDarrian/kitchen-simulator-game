# KrazyKitchen

A console based OOP project that simulates the hectic environment of a
restaurant during its busiest hours. The player manages customer orders
with time limits, tracks ingredient inventory, and restocks when needed,
all while running two modes side by side.

## Quick start

1. Install JDK 8 or later and make sure `javac` and `java` are on your PATH.
2. Double-click `run.bat` (or run it from a terminal in the project root).

That's it. `run.bat` compiles the source into `bin/` and launches the game
in one step, so there are no manual compile commands to type.

## Game concept

The program is split into two modes that run at the same time, on
separate threads, communicating so both stay in sync:

- Output Mode: a live view of the restaurant showing active orders,
  current inventory, and current score, refreshing every second.
- Input Mode: where the player types commands to actually process orders
  and manage the restaurant.

## Main menu

On start, the player is shown 4 options (input validated to 1 through 4):

1. Output Mode: prompts for a (non empty) player name, then starts the
   main game loop.
2. Input Mode: a command prompt for managing operations.
3. How to Play: a help screen explaining the two modes, scoring, and how
   to exit.
4. Exit: shows a splash/farewell screen and quits.

## Output Mode

Displays, refreshed every second:

- Restaurant's Name
- Active Orders: customer name, recipe name, reward, and time left for
  each order
- Current Inventory: quantity remaining of every ingredient
- Current Score

Pressing Enter exits the loop and shows the player's final score.

## Input Mode commands

- `process <order_number>`: process a specific active order. The game
  prompts for the ingredients needed and checks the input against the
  order's recipe.
  - Correct, in stock, not expired: reward added to score, inventory
    deducted, order removed.
  - Incorrect ingredients, insufficient stock, or expired order: order
    fails, no reward.
- `restock`: increases every ingredient's quantity by 10, at a cost of 30
  points. Requires the player's score to be 30 or above first.
- `exit`: returns to the main menu.

## Game systems

### Customers

Customers are modeled with an abstract base class (`Customer`) and two
concrete types:

- CasualCustomer: no bonus reward.
- VIPCustomer: additional +$10 reward bonus.

Each customer gets a random name (from a preset pool) and a random
patience value: `(random 1 to 20) + 15` seconds, which becomes the
order's time limit.

### Recipes

| Recipe | Ingredients |
|---|---|
| Cheeseburger | Bun, Cheese, Patty, Bun |
| Bacon Burger | Bun, Bacon, Patty, Lettuce, Tomato, Bun |
| Veggie Burger | Bun, Lettuce, Tomato, Onions, Pickles, Bun |
| Deluxe Burger | Bun, Cheese, Bacon, Patty, Lettuce, Tomato, Onions, Bun |

### Reward formula

```
BaseReward = 5 + (Number of Ingredients x 2)
Reward     = BaseReward + Customer's Additional Reward (VIP only)
```

### Orders (`restaurant.txt`)

Active orders are generated by pairing a random customer with a random
recipe, then persisted to `restaurant.txt` so they can be read and
updated as the game runs.

```
No#CustomerName#RecipeName#TotalReward#Time
```

Expired orders (timer reaches 0) are removed with no reward; completed
orders are removed and their reward is applied to the score.

### Inventory (`inventory.txt`)

Starting stock, 10 units of each ingredient:

```
Bun, Patty, Lettuce, Cheese, Tomato, Bacon, Pickles, Onions
```

Persisted in the format:

```
IngredientName#Quantity
```

Processing an order deducts the used ingredients; `restock` adds 10 to
every ingredient.

### Score (`score.txt`)

The player's running score, persisted between reads/writes as the game
plays: `+Reward` per completed order, `-30` per restock.

## Project structure

```
src/
  main/
    Main.java             # game loop, menus, input/output modes, threading
  models/
    Customer.java         # abstract base customer class
    CasualCustomer.java   # customer variant, no bonus
    VIPCustomer.java      # customer variant, +$10 bonus
    Order.java            # a single customer order (recipe, reward, timer)
    Ingredient.java       # an inventory ingredient (name, quantity)
bin/            # compiled classes (created/updated by run.bat)
inventory.txt   # current ingredient stock
restaurant.txt  # current active orders
score.txt       # persisted player score
run.bat         # one-click compile and launch
```

## Requirements

- JDK 8 or later (with `javac` and `java` on your PATH)
- Windows (for `run.bat`)

## Running it

### Easiest: the batch file

Double-click `run.bat`, or from a terminal in the project root:

```bat
run.bat
```

The script switches to the project root automatically, so
`inventory.txt`, `restaurant.txt`, and `score.txt` are always found. If
compilation fails or Java isn't installed, it prints an error and waits
before closing so you can read it.

### Manual (macOS / Linux, or if you prefer)

```bash
javac -d bin src/main/Main.java src/models/*.java
java -cp bin main.Main
```

Run these from the project root so the `.txt` data files are found.

### From Eclipse

1. `File > Import > Existing Projects into Workspace`
2. Select this repository's root folder
3. Run `Main.java` as a Java Application
